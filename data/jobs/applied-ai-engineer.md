You will:

- Build RAG pipelines with hybrid search and measure retrieval quality
- Design an agent loop with tool use and recovery when a tool fails
- Own an evaluation suite that blocks a release when faithfulness drops
- Add guardrails for prompt injection
- Expose two tools over the Model Context Protocol
- Containerize the service with Docker and deploy it on Kubernetes
- Join the on-call rotation for a production model serving path

Required:

- 3+ years of Python
- Hands-on LLM application work

The team uses SQL for analytics and TypeScript for the product UI.
